{% comment %} Alert Box — colored callout for tips, warnings, and notes Parameters: - text: alert content (required; markdown supported) - class: info | warning | danger | success (default: info) - title: heading above the alert text (optional) - heading-level: integer 1–6, the heading level for `title` (default: 3) On heading-level: an alert does not know what section it sits in, and a fixed level creates gaps in the document outline — a callout under an h2 emitting an h4 skips h3. The default of 3 is right under the h2 sections most pages use; pass the level explicitly when nesting deeper. role="alert" is deliberately not used: it interrupts screen readers to announce live changes, which is wrong for static page content. These are notes, so they are marked as such. {% endcomment %} {% assign alert_class = include.class | default: 'info' %} {% assign heading_level = include.heading-level | default: 3 | append: '' %} {% assign valid_levels = '1,2,3,4,5,6' | split: ',' %} {% assign valid_classes = 'info,warning,danger,success' | split: ',' %} {% case alert_class %} {% when 'warning' %}{% assign alert_label = 'Warning' %} {% when 'danger' %}{% assign alert_label = 'Danger' %} {% when 'success' %}{% assign alert_label = 'Success' %} {% else %}{% assign alert_label = 'Information' %} {% endcase %} {% if include.text and valid_levels contains heading_level and valid_classes contains alert_class %}
{{ alert_label }} {% if include.title %} {{ include.title | escape }} {% endif %} {{ include.text | markdownify }}
{% else %}
